### 2.3 HTTPS, HSTS & Redirect Behavior
Probes executed against all domain permutations:
1. `https://nixora.co.in/` -> **200 OK** (`Server: Vercel`, `Strict-Transport-Security: max-age=63072000`)
2. `http://nixora.co.in/` -> **308 Permanent Redirect** -> `Location: https://nixora.co.in/` (1 hop)
3. `https://www.nixora.co.in/` -> **308 Permanent Redirect** -> `Location: https://nixora.co.in/` (1 hop)
4. `http://www.nixora.co.in/` -> **308 Permanent Redirect** -> `Location: https://www.nixora.co.in/` -> **308 Permanent Redirect** -> `Location: https://nixora.co.in/` (2 hops)

**Recommendation:** While Vercel handles standard HTTPS redirection smoothly, updating DNS or Vercel domain routing to redirect `http://www.nixora.co.in/` directly to `https://nixora.co.in/` in 1 hop will eliminate redirect latency for users typing the full WWW address.

### 2.7 Defect: Header Logo Missing Width & Height (CLS Risk)
- **Source:** `src/components/Header.astro:13`
  ```html
  <!-- Current code -->
  <a href="/" class="logo-link" aria-label="Nixora Home">
    <img src="/logo.svg" alt="Nixora" />
  </a>
  ```
- **Severity:** High (P1)
- **Issue:** Modern web browsers reserve layout space during parsing only when explicit `width` and `height` dimensions are defined on `<img>` elements. Without dimensions, the logo area occupies 0px height before the SVG loads, causing the header and subsequent hero text to shift down when rendered (Cumulative Layout Shift).
- **Fix:** Update to:
  ```html
  <img src="/logo.svg" alt="Nixora" width="90" height="26" />
  ```
